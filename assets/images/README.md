# assets/images/

Dossier dédié aux images statiques du site (organisation propre, séparée du CSS/JS).

## Photo de profil

Place ta photo ici sous le nom exact :

    assets/images/profile.jpg

Recommandations :
- Format carré (ex. 800×800px minimum) pour un rendu net à toutes les tailles
- .jpg ou .png acceptés — si tu utilises .png, mets à jour l'attribut `src`
  dans `index.html` (`assets/images/profile.jpg` → `assets/images/profile.png`)
- Tant que le fichier n'existe pas, le site affiche automatiquement un
  repli avec tes initiales (aucune image cassée visible)

## Autres images futures

Si tu ajoutes des captures d'écran ou schémas dans un walkthrough (via Obsidian),
même logique : un sous-dossier dédié, ex. `assets/images/walkthroughs/`,
pour ne jamais mélanger avec les images de mise en page du site.
